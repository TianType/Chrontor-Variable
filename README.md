# Chrontor Variable

## Introduction / 字体介绍
Chrontor Variable is a futuristic grid‑based modular typeface inspired by Wim Crouwel’s *New Alphabet* from 1967. All glyphs are built purely with geometric straight lines. All diagonal strokes share a unified 45‑degree angle, bringing strong orderliness and minimalist constructive feeling. Its aesthetic is sterile, avant‑garde and distinctly sci‑fi‑flavoured. The name Chrontor originates from Chronos, god of time, meaning "the master of time".

Chrontor Variable is the variable‑axis version of Chrontor. It comes with two width styles Regular and Extended, supporting dynamic width adjustment. The character set covers basic Latin characters and a small set of supplementary symbols.

Chrontor Variable 是一款基于网格设计的未来主义模块化字体，灵感源自 Wim Crouwel 在1967年设计的 New Alphabet。字形完全由几何直线构成，所有斜线统一采用45°，拥有极强的秩序感与极简的建构感。整体风格冷峻前卫，带有鲜明的科幻气质。字体名称取自 Chronos（时间之神），寓意“时间的掌控者”。

Chrontor Variable 是 Chrontor 的可变版本，包含 Regular、Extended 两个字宽，支持字宽动态调节。字符集覆盖基础拉丁字符与少量补充符号。

## Special Design / 特色设计
The .notdef placeholder glyph, also known in the industry as "tofu box", will be displayed when a character not present in the font is called. Common default shapes are empty boxes, question marks or crosses. I specifically designed a Hanzi “無”(none), paired with Latin glyphs, to serve as this placeholder.

.notdef占位字形，业内也叫“豆腐块”，当调用字体不存在的字符时就会显示它，常见形态是方框、问号、叉号。我专门设计了一枚风格适配拉丁字母的汉字「無」充当该占位字形。
